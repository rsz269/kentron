# OCCT's DRAW scripts, as they are

Copied from OCCT's `tests` by `tools/draw2rs.py`: the scripts it does not convert to Rust,
which `tests/draw_tcl.rs` runs on a Tcl interpreter (`src/draw/tcl.rs`), with their groups'
and grids' `begin` and `end` files and `parse.rules`. LGPL-2.1 with the Open CASCADE
exception, as OCCT (see `../README.md`). Do not edit; re-run the tool instead.
