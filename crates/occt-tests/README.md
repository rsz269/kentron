# occt-tests

Tests ported from Open CASCADE Technology (OCCT), run against kentron:

- `cases/`: YAML test cases (`docs/test-cases.md`), run by the `cases` test target.
- `tests/draw_*`: OCCT DRAW scripts not expressible in YAML, generated by `tools/draw2rs.py`.
- `tests/gtest_*`: hand translations of OCCT's GTests (`GTEST_PORTING.md`).

## Expected failures

Tests of known gaps in kentron are marked as expected to fail: they pass while they fail
and fail once they pass, so that a fix shows as clearly as a regression.

- Converted DRAW scripts are listed in `expected_failures.txt` (by OCCT script path);
  `tools/draw2rs.py` marks their YAML cases `expect: not_done` and their Rust tests
  `#[should_panic]`. When one starts to pass, remove it from the list and re-run the tool.
- Hand-written tests carry their own marks: `expect: not_done` in YAML, `#[should_panic]`
  with a comment in Rust.

## OCCT test data

Many OCCT tests read shapes from OCCT's test dataset, which is not part of this repository
(nor of OCCT's): it is an external download of about 100 MB (350 MB unpacked).

```sh
mkdir -p ~/occt-data && cd ~/occt-data
wget https://github.com/Open-Cascade-SAS/OCCT/releases/download/V7_9_0_beta1/opencascade-dataset-7.9.0.tar.xz
tar -xf opencascade-dataset-7.9.0.tar.xz && rm opencascade-dataset-7.9.0.tar.xz
```

Files are looked up by name, recursively, in the directories listed in `OCCT_TEST_DATA`
(path-list syntax), then in `~/occt-data`, `$OCCT_ROOT/data` and `~/OCCT/data`.

Without the data, YAML cases that load it are skipped (reported as ignored, with the missing
file), and generated Rust tests that need it fail with "OCCT test data file not found". Some
files OCCT's scripts use were never published; their cases are always skipped.

The tools use the same data: `tools/draw2rs.py` (`--data-dir`, default `~/occt-data`) and
`tools/occt_selectors.py`, which runs OCCT's DRAW with `CSF_TestDataPath` set to
`OCCT_TEST_DATA` or `~/occt-data`.

## BRL-CAD test files

The cases in `cases/brlcad` read STEP files from a BRL-CAD source checkout: NIST's MBE PMI
test parts (`db/nist`) and the STEP exports in `src/libbrep/tests`. They are looked up in
its `db` and `src/libbrep/tests` directories, under `BRLCAD_SRC` or else `~/brlcad`:

```sh
git clone --depth 1 https://github.com/BRL-CAD/brlcad.git ~/brlcad
```

(When the official repository is unavailable, as it was in October 2026, a mirror serves:
`https://gitverse.ru/geoceti/brlcad.git`.)

Their expected values are OCCT's reading of the same files (DRAW `stepread`, then
`sprops`/`vprops` at 1e-9 and `nbshapes`), as BRL-CAD's tests give none.
